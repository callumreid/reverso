# Phase 1 – Foundations

## Objectives
- Lock MVP scope, success metrics, and acceptance criteria from `TECHNICAL_DESIGN.md`
- Stand up Next.js + TypeScript project with pnpm, ESLint, Prettier, and testing framework
- Establish base folder structure, path aliases, and shared config files
- Document environment variable strategy and bootstrap `.env.example`
- Prepare Vercel deployment hooks and scripts for local dev

## Tasks
1. Review and capture scope summary + non-goals
2. Initialize Next.js app with pnpm using `create-next-app`
3. Configure TypeScript strict mode, ESLint, Prettier, Husky lint-staged (if needed)
4. Set up Tailwind (or chosen styling approach) and global styles baseline
5. Create skeleton folders per section 2 of technical design (`components`, `hooks`, etc.)
6. Add environment docs (`.env.example`, README setup section)
7. Verify dev server runs locally (`pnpm dev`)

## Deliverables
- New Next.js repo scaffold with configs committed
- Documented scope summary and local setup instructions
- `.env.example` populated with required keys placeholders
- Confirmation of successful local dev run
